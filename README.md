# Center Console Board

Autonomous Vehicle (AV) triage + fleet operations demo dashboard.

## Run

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:4173/`.

## Build

```bash
npm run build
npm run preview
```

## Notes

- Demo auth + simulated data (optional Supabase if env vars set).
- Ticket Monitoring Map uses MapLibre (mapcn-style integration).
